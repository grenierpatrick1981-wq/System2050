# 🧠 System∩2050 — Cadre pour l’Ignition Cognitive
### A framework for modeling civilizational balance through systemic convergence

![DOI](https://img.shields.io/badge/DOI-10.5281%2Fzenodo.17501970-blue)

---

## 🎯 Objectif
**System∩2050** est un modèle mathématique de stabilité civilisationnelle basé sur la relation entre énergie, cognition, structure et harmonie.  
Il sert à mesurer l’équilibre entre la puissance technologique et la cohésion sociale.

> **Formule centrale :**
> \( k = \frac{E \times C}{S \times H} \)

---

## ⚙️ Variables fondamentales

| Symbole | Nom | Description |
|----------|------|-------------|
| **E** | Énergie | Intensité économique et énergétique |
| **C** | Cognition | Cohérence cognitive collective |
| **S** | Sens | Cohésion éthique et sociale |
| **H** | Harmonie | Stabilité systémique |
| **K** | Friction | Résistance interne au changement |

---

## 🔥 Triple condition d’Ignition Cognitive

| Condition | Formule | Seuil | Interprétation |
|------------|----------|--------|----------------|
| Équilibre dynamique | 0.8 < k < 1.2 | ✓ | Zone d’ignition optimale |
| Maturité systémique | Σ = (E + C + S + H) / 4 > 0.65 | ✓ | Système prêt pour la convergence |
| Friction maîtrisée | K < 0.4 | ✓ | Résistance contrôlée |
| Condition dynamique | n·T·τ > K | – | Maintien du flux adaptatif |

---

## 🧩 Validation historique (1000–2025)

| Période | k | Σ | K | Statut |
|----------|---|---|---|--------|
| 1945–1970 | 1.07 | 0.74 | 0.25 | ✅ Ignition harmonique |
| 1990–2000 | 0.99 | 0.82 | 0.20 | ✅ Ignition harmonique |
| 2007–2015 | 1.64 | 0.77 | 0.35 | ⚠️ Surinvestissement |
| 2020–2025 | 2.42 | 0.74 | 0.55 | ❌ Déséquilibre critique |
